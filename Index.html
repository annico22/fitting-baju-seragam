    Cara Pakai di Lokasi

    1. Siswa datang, sebutkan nomor pendaftaran — ketik di form, pastikan statusnya hijau.
    2. Ukur dan cobakan tiap seragam, isi ukurannya persis seperti di formulir kertas (angka untuk formal, huruf untuk olahraga).
    3. Simpan, lalu cetak formulirnya untuk ditandatangani dan dibawa siswa saat pengambilan seragam.
    4. Hitungan ukuran per seragam di menu Rekap dipakai untuk rekap pesanan ke penjahit/vendor.

    Soal Cetak

    Hasil cetak adalah formulir kertas koperasi dalam ukuran A4 — kop, tabel seragam, tanda tangan, dan catatan tampil persis seperti blanko aslinya. Cara paling pasti dari pratinjau ini: pakai tombol Unduh Bukti (HTML), buka filenya di browser, lalu tekan Ctrl+P — dari dialog cetak bisa langsung ke printer atau dipilih Save as PDF.

    Kelola User

    Buat akun Admin maupun Petugas Fitting dan reset password-nya bila pemilik akun lupa. Menu ini hanya untuk Admin yang sudah masuk dengan akunnya.

    Buat User Baru

    Isi nama, username, peran, dan password awal. Sampaikan username dan password ini langsung ke pemilik akun — ia masuk dari halaman login dengan data tersebut, dan perannya mengikuti akun ini.

    Huruf kecil, angka, titik, atau garis bawah. Tanpa spasi, minimal 3 karakter, dan tidak boleh sama dengan akun lain — Admin maupun petugas.

    Petugas Fitting: hanya input data fitting, lihat rekap, dan cetak formulir.

    Akun yang dibuat berlaku selama halaman ini dibuka, sama seperti data fitting di halaman ini.

    Cara kerjanya

    1. Admin membuat user di form ini: nama, username, peran (Admin atau Petugas Fitting), dan password awal.
    2. Pemilik akun masuk dari halaman login dengan username dan password tersebut — tidak ada lagi pilihan peran di halaman login, peran mengikuti akun.
    3. Admin bisa input, edit, hapus, unduh CSV, dan mengelola user. Petugas Fitting hanya bisa input data, melihat rekap, dan mencetak formulir.
    4. Kalau ada yang lupa password, Admin menekan tombol Reset Password pada daftar di bawah dan mengisikan password baru.
    5. Password lama langsung tidak berlaku setelah direset.

    Daftar User

    Semua akun — Admin dan Petugas Fitting. Password tidak ditampilkan. Untuk mengganti password seseorang, pakai tombol Reset Password di barisnya; untuk menghapus akun, pakai tombol Hapus di barisnya.

    Pratinjau Formulir — Siap Cetak

    Beginilah tampilan formulir koperasi yang tercetak di kertas A4. Unduh buktinya lalu buka filenya di browser untuk mencetak ke printer atau menyimpannya sebagai PDF. Halaman ini dibuka dari browser lengkap? Tekan Ctrl+P — yang tercetak hanya formulir ini.
